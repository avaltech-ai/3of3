# iPad／iPhone Safari 實機驗收清單

> 為什麼要做：桌面瀏覽器模擬取代不了實機，過去重大 bug 多為 Safari 特有。
> 網址：https://avaltech-ai.github.io/3of3/?fresh=1（`?fresh=` 後面隨便改數字，可繞過約 10 分鐘的頁面快取）
> 每項請記「通過／不通過」，不通過請截圖並寫下機型與 iOS 版本。

**測試裝置**：機型＿＿＿＿　iOS 版本＿＿＿＿　方向：直放／橫放

## A. 載入與基本版面
- [ ] 1. 開啟首頁，轉圈圈後 5 秒內出現內容，沒有一直停在載入畫面。
- [ ] 2. 頁面有樣式（顏色、卡片），不是純白底黑字（Tailwind 載入成功）。
- [ ] 3. 直放與橫放都沒有橫向捲動、文字沒被切掉。
- [ ] 4. iPad：左側選單釘選／展開不遮住內容；iPhone：底部導覽列各按鈕可點、沒被 Safari 工具列蓋住。

## B. 語言切換
- [ ] 5. 切到英文：公開頁面各處（日曆、相簿、文件、唱跳音符）介面文字為英文，無殘留中文介面字。
- [ ] 6. 英文介面下，相簿／文件／歌曲類別、學期、活動對象顯示 NameMap 的英文；切回中文恢復中文。

## C. 日曆與活動
- [ ] 7. 點日期可看到當天詳情；「即將到來」列表正常。
- [ ] 8. 焦點活動輪播可左右切換、放大查看，左右箭頭位置不跳動。

## D. 影像紀錄（相簿）
- [ ] 9. 相簿封面正常顯示（不是破圖或灰色佔位圖）；重新整理同一天封面不變。
- [ ] 10. 進入相簿能看到照片、點擊放大；左右切換、自動播放／停止可用。
- [ ] 11. 影片可播放（播放需點擊，Safari 會擋自動有聲播放，屬正常）。

## E. 常用文件
- [ ] 12. 文件清單可依類別篩選；點文件能開啟或下載。

## F. 唱跳音符
- [ ] 13. 勾選歌曲，底部「已選取 N 首」數字與畫面勾選數一致；切換篩選後數字只算目前篩選內的。
- [ ] 14. 按播放，音樂可播放；手機直放時卡片版面不擠（勾選框在縮圖上、歌名最多 3 行）。
- [ ] 15. 鎖定螢幕或切到別的 App 再回來，播放器仍正常。

## G. 管理後台（僅限管理員，用真實密碼，不要在公用裝置做）
- [ ] 16. 可登入；登入後「管理員已登入」徽章與登出鈕在右上角。
- [ ] 17. 新增一筆測試活動後儲存，顯示成功，約 5 分鐘內前台出現；之後刪除該測試活動。
- [ ] 18. 登出後重新整理，需重新登入（token 不殘留）。
